# Security policy

## Supported versions

Security fixes are released for the latest minor version. Please upgrade to the latest
release before reporting a problem.

## Reporting a vulnerability

Please don't open a public issue for security problems.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/hmdsefi/gograph/security/advisories/new),
or by email to hdyousefi@gmail.com.

Please include:

- the gograph version and Go version
- a description of the problem and its impact, for example a panic, excessive memory
  use or a hang on crafted input
- a minimal program that reproduces it

You'll get an acknowledgment within 7 days. Once the problem is confirmed, a fix is
prepared and released, and the report is credited in the release notes unless you'd
prefer otherwise.
